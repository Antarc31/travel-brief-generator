Esporta la dashboard sul telefono, prima di partire

Una volta che dashboard-viaggio.html è pronto sul computer, portalo sul telefono così — vale qualunque AI tu abbia usato per generarlo. Fallo prima di partire, con calma, non in viaggio.

Apple ha bloccato negli ultimi aggiornamenti di iOS l'apertura di un file HTML locale direttamente in Safari, per motivi di sicurezza: l'anteprima nell'app File resta, ma non esegue JavaScript, quindi le sezioni interattive (packing list, budget) non funzionerebbero. Il metodo qui sotto aggira il problema mettendo il file online con un link vero, che Safari apre normalmente.
  1. A

    Rinomina il file in index.html

    Sul computer, prima di caricarlo, rinomina il file scaricato in esattamente index.html (tutto minuscolo). È il passaggio che evita l'errore "Page not found" più comune: Netlify mostra automaticamente solo un file con questo nome quando apri il link principale del sito — con qualsiasi altro nome, quel link resta vuoto anche se il sito esiste.

  2. B

    Vai su app.netlify.com/drop e trascina il file

    È un servizio gratuito per pubblicare file HTML online: nessun account richiesto per il primo caricamento. Trascina index.html direttamente sulla pagina. In pochi secondi ottieni un link tipo https://nome-a-caso-123.netlify.app.

    app.netlify.com/drop
    Trascina qui il file index.html

    Illustrazione del browser — l'interfaccia reale può variare.

  3. C

    "Rivendica" il link (importante)

    Senza un account, il link scade dopo poche ore. Il sito ti proporrà di crearne uno gratuito (basta un'email) per "rivendicare" (claim) quel link e tenerlo attivo per tutta la durata del viaggio. Fallo, altrimenti rischi di trovarlo scaduto quando sei già partito.

  4. D

    Manda il link al telefono e aprilo in Safari

    Mandati il link (email, messaggio, note) e aprilo in Safari: funziona come un sito vero, packing list e budget compresi. Poi tocca l'icona di condivisione → "Aggiungi a Home" per avere un'icona a tutti gli effetti.

Vedi comunque "Page not found"? Il file caricato su Netlify probabilmente non si chiamava index.html (attenzione anche a maiuscole/minuscole: Index.html non basta). Due modi per risolvere: ricarica il file dopo averlo rinominato correttamente, oppure — soluzione rapida senza ricaricare nulla — aggiungi il nome esatto del file alla fine del link, es. https://nome-a-caso.netlify.app/dashboard-viaggio.html.
Il link è pubblico ma con un indirizzo casuale e non indicizzato: chiunque non lo conosca non lo trova. Non contiene però una password, quindi non condividerlo pubblicamente se ci sono dati che preferisci tenere privati.

Su Android hai due strade, entrambe affidabili: mettere il file online (più comodo, un solo link) oppure aprirlo in locale (niente da caricare online).

  1. A
